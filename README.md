# Phase 2 - Core Concepts and Skills

## Student Management System

This project was developed as part of **Phase 2 of the internship**, focusing on building a strong understanding of core Java concepts and applying them through a practical project.

The project is a **console-based Student Management System** that allows users to manage student records.

## Features

- Add Student
- View All Students
- Search Student by ID
- Update Student Information
- Delete Student
- Handle Invalid Input
- Exit the Application

## Core Java Concepts Used

- Variables and Data Types
- Operators
- Conditional Statements
- Switch Statement
- Loops
- Methods
- Classes and Objects
- Constructors
- Encapsulation
- Getters and Setters
- ArrayList
- Exception Handling
